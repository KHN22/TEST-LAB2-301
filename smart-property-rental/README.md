# SmartLiving Property — Rental Lab

ระบบทดลองจัดการสัญญาเช่าและเงินประกันตามโจทย์ที่ 4 ใช้ Smart Contract บน Sepolia และหน้าเว็บแบบ Static สำหรับ GitHub Pages

## 1. Deploy Smart Contract ใน Remix

1. เปิด [Remix IDE](https://remix.ethereum.org/) แล้วนำไฟล์ `contracts/SmartPropertyRental.sol` เข้า workspace
2. ใน Solidity Compiler เลือก **0.8.30** และ **EVM Version: Shanghai** หากต้องการใช้การตั้งค่าเดียวกับที่ทดสอบ ให้เปิด Optimization (200 runs) แล้ว Compile
3. เชื่อม Wallet เจ้าของห้องที่มี Sepolia ETH ในหน้า Deploy & Run เลือก **Browser Extension** (หรือ **Injected Provider** ตามเวอร์ชัน Remix) ตรวจว่า Wallet อยู่บน Sepolia แล้ว Deploy สัญญา `SmartPropertyRental` โดยใช้ Value 0
4. คัดลอก Contract Address หลังธุรกรรมยืนยัน

## 2. เปิดเว็บบน GitHub Pages

1. แตก ZIP แล้วนำ **ไฟล์ทั้งหมดภายใน** โฟลเดอร์ `smart-property-rental` ไปไว้ที่ root ของ GitHub repository สาขา `main` ให้เห็น `index.html` ที่ root และเก็บโครงสร้าง `vendor/` ตามเดิม
2. เปิด **Settings → Pages → Build and deployment** เลือก **Deploy from a branch → main → /(root)** แล้ว Save
3. เปิด URL ที่ GitHub Pages แสดง วาง Contract Address แล้วกด **เชื่อมต่อ Wallet** หน้าเว็บใช้ ABI ที่แนบมาและไม่ต้องติดตั้ง npm หรือ build ก่อนอัปโหลด

อ้างอิง [GitHub Pages publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

หากทดลองหน้าเว็บบนเครื่อง ให้เปิด Terminal ในโฟลเดอร์นี้ รัน `python -m http.server 8000` แล้วเปิด [localhost:8000](http://localhost:8000/) เพื่อให้หน้าเว็บโหลด `abi.json` ผ่าน HTTP

## 3. ทดลองตามโจทย์

ใช้ Wallet แยก 3 บัญชีบน Sepolia ได้แก่ เจ้าของห้อง ผู้เช่า และผู้ชี้ขาด ให้แต่ละบัญชีมี Test ETH สำหรับค่า gas ตัวอย่างนี้ใช้ค่าเช่า **0.001 ETH** และเงินประกัน **0.005 ETH** ผู้เช่าควรมีเงินพอสำหรับทั้งสองยอดและค่า gas

| ขั้น | Wallet | การทดลอง |
| --- | --- | --- |
| 1 | เจ้าของ | ลงทะเบียนห้อง A101 ตั้งค่าเช่าและเงินประกัน แล้วจด Property ID |
| 2 | เจ้าของ | สร้างสัญญาด้วย Property ID ระบุ Wallet ผู้เช่าและผู้ชี้ขาด ตั้งเวลาเริ่มในอนาคตและเผื่อเวลาสำหรับกดยืนยันกับชำระเงิน จด Agreement ID |
| 3 | เจ้าของและผู้เช่า | เปิดรายละเอียดสัญญา ตรวจข้อมูล แล้วใช้ Wallet ของแต่ละคนกดยืนยัน |
| 4 | ผู้เช่า | ฝากเงินประกันหลังยืนยันครบสองฝ่าย ตรวจสถานะและยอดที่ถือไว้ |
| 5 | ผู้เช่า | หลังถึงเวลาเริ่ม ให้ชำระงวด 1 ก่อนหมดสัญญา แล้วค้นหางวด 1 เพื่อตรวจยอดและเวลาชำระ |
| 6A | เจ้าของ → ผู้เช่า | หลังหมดสัญญา เจ้าของบันทึกผลตรวจและยอดหัก เช่น 0.002 ETH ผู้เช่าโหลดผลตรวจ ตรวจยอดคืน 0.003 ETH แล้วกดอนุมัติ |
| 6B | ผู้เช่าหรือเจ้าของ → ผู้ชี้ขาด | ใช้สัญญาอีกฉบับที่ฝากเงินแล้วและหมดอายุ เปิดข้อพิพาทก่อนอนุมัติคืนเงิน สลับไป Wallet ผู้ชี้ขาด บันทึกคำตัดสินและยอดหัก เช่น 0 เพื่อคืนเต็ม |
| 7 | ผู้เช่าและเจ้าของ | ตรวจยอด ETH ที่ถอนได้ ถอนด้วย Wallet ของแต่ละฝ่าย และเปิดธุรกรรมบน Sepolia Etherscan |

## กติกาของชุดทดลอง

- ค่าเช่าคิดเป็นงวดละ 30 วันนับจากเวลาเริ่มสัญญา งวดที่เริ่มแล้วจ่ายย้อนหลังได้ตามลำดับก่อนหมดสัญญา งวดสุดท้ายใช้ค่าเช่าเต็มตามที่ลงทะเบียน
- การหักเงินตามผลตรวจต้องมีข้อความประกอบจากเจ้าของและการอนุมัติจากผู้เช่า หากเปิดข้อพิพาทแล้ว ผลตัดสินของผู้ชี้ขาดจะเป็นตัวกำหนดยอดหัก ยอดหักรวมกับยอดคืนเท่ากับเงินประกันที่ยังถืออยู่
- ระบบจัดสรรเงินเข้าเป็นยอดที่ถอนแยกตาม Wallet หลังการชำระค่าเช่าหรือการอนุมัติคืนเงิน ผู้รับต้องกดถอน ETH เพื่อโอนเข้ากระเป๋า
- สัญญาแต่ละห้องสร้างฉบับถัดไปได้เมื่อฉบับก่อนหมดอายุ เงินประกันฉบับเดิมยังจัดการได้ด้วย Agreement ID เดิม หากไม่มีการอนุมัติหรือคำตัดสิน เงินประกันยังอยู่ในสัญญา ชุดทดลองนี้ไม่มีการยกเลิกก่อนกำหนดหรือคืนเงินอัตโนมัติ
- ข้อมูลห้อง เงื่อนไข และข้อความข้อพิพาทอ่านได้สาธารณะจาก Blockchain ให้ใช้ข้อมูลสมมติ

## ผลตรวจ

คอมไพล์ด้วย Solidity 0.8.30 และทดสอบบน Local EVM ตั้งแต่ลงทะเบียนถึงถอน ETH ครอบคลุมทั้งการอนุมัติคืนและข้อพิพาท รวมถึงการปฏิเสธบทบาทที่ไม่มีสิทธิ์ ค่าเช่าซ้ำ ยอด ETH ผิด และการหักเกินเงินประกัน

ทดสอบ JavaScript ของหน้าเว็บด้วย DOM จำลองที่เชื่อมกับ Local EVM โดยตรวจการเปิดฟอร์ม การเชื่อม Wallet การลงทะเบียน การแสดงลิงก์ธุรกรรม และการอ่านข้อมูลห้อง การเผยแพร่บน GitHub Pages และการส่งธุรกรรมจริงบน Sepolia ทำตามขั้นตอนด้านบน
